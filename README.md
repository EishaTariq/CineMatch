# 🎬 CineMatch AI

An AI-powered Movie + Book Recommendation Android App built with Kotlin.

## Features
- 🎭 Mood-based movie recommendations using Machine Learning
- 📚 Book recommendations for novel-based movies
- ⭐ Favorites/Watchlist with local Room database
- 🌙 Dark cinematic theme
- 🎬 Bollywood, Lollywood & Hollywood support

## Tech Stack
- **Android**: Kotlin, Room DB, Retrofit, Glide, Coroutines
- **Backend**: Python, Flask, Scikit-learn, Naive Bayes
- **Deployment**: Railway.app (API), Streamlit Cloud (Web App)

## ML Model
- Algorithm: Naive Bayes (75% accuracy)
- Dataset: MovieLens + custom Bollywood/Lollywood data
- Features: Mood, Energy, Company, Length, Industry
